1. Receive the merged dataset

The merge agent sends you the folder $merged, over a secure channel, expected around $time_merge. It holds one CSV file for each table:

    $merged_tables

Save them where your organization holds the project's data. The column $id holds each person's id, the same in every table. It is new: a random number, drawn when the tables were merged, so that no row can be traced back to a site's records. No site's own ids, and no study ids, are in the dataset.

2. Confirm

Check that you have every table above, then tell $contact_name. Delete any other copy outside your own storage, wherever it was shared, such as in your downloads folder.
