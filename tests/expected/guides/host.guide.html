1. Receive the merged dataset

The merge agent sends you the folder merged/, over a secure channel, expected around 16:30 on Monday 16 November 2026. It holds one CSV file for each table:

  • merged/scores.csv: the columns person_id and score; one row for each person_id.

Save them where your organization holds the project's data. The column person_id holds each person's id, the same in every table. It is new: a random number, drawn when the tables were merged, so that no row can be traced back to a site's records. No site's own ids, and no study ids, are in the dataset.
